So, Avinash,

```bash
# New Next.js project
pnpm create next-app@latest

# Initialize shadcn/ui in an existing Next.js + Tailwind project
pnpm dlx shadcn@latest init

# Or scaffold/init with the Next.js template
pnpm dlx shadcn@latest init -t next
```

```bash
# Add one component
pnpm dlx shadcn@latest add button

# Add requested components in one command
pnpm dlx shadcn@latest add button card badge input select sheet dialog tabs accordion table separator skeleton
```

Key caveats:

- Use `shadcn`, not the old `shadcn-ui` package name:
  ```bash
  pnpm dlx shadcn@latest ...
  ```
- Run `init` before `add` in an existing project.
- Existing/custom Next.js projects need Tailwind configured and an import alias like `@/*`.
- The CLI writes component source into your project; it is not installed as a traditional component package.
- Official docs: https://ui.shadcn.com/docs/installation/next and https://ui.shadcn.com/docs/cli
